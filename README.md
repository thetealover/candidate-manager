# candidate-manager

A task-purposed, Java 21 + Micronaut microservice responsible for candidate registration and eligibility verification for a professional certification program.

## Quick start

```bash
# Boot the full stack (Postgres + service) in one shot
docker compose up --build

# OR: run the service in IntelliJ / the shell against a local Postgres
docker compose up -d candidate-manager-ws-postgresql
MICRONAUT_ENVIRONMENTS=local ./gradlew :api:run
```

The service listens on `:8080`.

## OpenAPI / Swagger UI

Generated at compile time by the Micronaut OpenAPI annotation processor and **exposed only in the `local` environment** (intentionally — see [API contract spec](docs/superpowers/specs/2026-05-18-03-api-contract-design.md#openapi)).

When running with `MICRONAUT_ENVIRONMENTS=local`:

| What       | URL                                                                              |
|------------|----------------------------------------------------------------------------------|
| Swagger UI | <http://localhost:8080/swagger-ui/index.html>                                    |
| Redoc      | <http://localhost:8080/swagger-ui/redoc/index.html>                              |
| RapiDoc    | <http://localhost:8080/swagger-ui/rapidoc/index.html>                            |
| Raw spec   | <http://localhost:8080/swagger/candidate-manager-ws-api-0.1.0.yml>               |

In `dev`, `test`, or the default profile these paths return 404.

The view bundles are generated by the annotation-processor flag in `api/build.gradle`:

```
-Amicronaut.openapi.views.spec=swagger-ui.enabled=true,redoc.enabled=true,rapidoc.enabled=true
```

If `/swagger-ui/index.html` 404s after a clean checkout, run `./gradlew :api:clean :api:compileJava` to regenerate the bundle.
