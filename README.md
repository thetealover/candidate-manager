# candidate-manager

A Java 21 / Micronaut microservice that manages candidate registration and
eligibility verification for a professional certification program. Built as a
test task for the CFA Institute BERT Modernization initiative
(.NET monolith → Java microservices on AWS EKS).

## Quick start

```bash
# Boot the full stack (Postgres + service) in one command
docker compose up --build

# OR: run the service against a local Postgres container
docker compose up -d candidate-manager-ws-postgresql
MICRONAUT_ENVIRONMENTS=local ./gradlew :api:run
```

Service binds to <http://localhost:8080>. Health: `GET /health` → `{"status":"UP"}`.

## Project layout

| Module           | Purpose                                                                |
|------------------|------------------------------------------------------------------------|
| `domain`         | Pure Java aggregates, value objects, ports, business rules. No framework imports. |
| `application`    | Use cases and async handlers (Micronaut DI); per-feature sub-packages.  |
| `infrastructure` | JPA entities, mappers, Micronaut Data repositories, Liquibase, event publisher. |
| `api`            | REST controllers, DTOs, RFC 7807 exception handlers, request filter.   |

Dependencies point inward: `api` and `infrastructure` depend on
`application`/`domain`; `domain` depends on nothing. See
[`DECISIONS.md` §D1](DECISIONS.md) for the rationale.

## Build & test

```bash
./gradlew check                # all tests + Spotless + JaCoCo 80% gate on :domain
./gradlew :domain:test         # fast domain unit tests (no Docker required)
./gradlew :api:test            # HTTP e2e tests (Testcontainers Postgres)
./gradlew :infrastructure:test # adapter integration tests (Testcontainers Postgres)
./gradlew spotlessApply        # auto-format
```

Testcontainers requires a running Docker daemon. On macOS, the build files
auto-detect the Docker socket and disable Ryuk; no extra setup needed.

## OpenAPI / Swagger UI

Generated at compile time by the Micronaut OpenAPI annotation processor and
**exposed only in the `local` environment** (intentional — see the
[API contract spec](docs/superpowers/specs/2026-05-18-03-api-contract-design.md#openapi)).

When running with `MICRONAUT_ENVIRONMENTS=local`:

| View       | URL                                                                |
|------------|--------------------------------------------------------------------|
| Swagger UI | <http://localhost:8080/swagger-ui/index.html>                      |
| Redoc      | <http://localhost:8080/swagger-ui/redoc/index.html>                |
| RapiDoc    | <http://localhost:8080/swagger-ui/rapidoc/index.html>              |
| Raw spec   | <http://localhost:8080/swagger/candidate-manager-ws-api-0.1.0.yml> |

In `dev`, `test`, or the default profile these paths return 404.

The view bundles are generated by the annotation-processor flag in
`api/build.gradle`:

```
-Amicronaut.openapi.views.spec=swagger-ui.enabled=true,redoc.enabled=true,rapidoc.enabled=true
```

If `/swagger-ui/index.html` 404s after a clean checkout, run
`./gradlew :api:clean :api:compileJava` to regenerate the bundle.

## Configuration

Three Micronaut environments:

| Environment | Purpose                                                                                 |
|-------------|-----------------------------------------------------------------------------------------|
| `local`     | docker-compose Postgres, plain Logback layout, test-data Liquibase context active, Swagger UI exposed. |
| `dev`       | Secrets injected via env vars (intended target: AWS Secrets Manager). JSON logs via `logstash-logback-encoder`. Swagger UI 404. |
| `test`      | Auto-activated by Micronaut when JUnit is on the classpath. Used by `@MicronautTest` e2e ITs. |

Activate via the `MICRONAUT_ENVIRONMENTS` env var.

**Rate limiting** is configured under the top-level `rate-limit.*` block in
`application.yml` (per-IP read/write, per-actor write, Caffeine cache
sizing). Disable by setting `rate-limit.enabled: false`. See
`DECISIONS.md` §D20.

## What I'd do next

If the budget were larger, in order of payoff:

- Replace in-memory event delivery with a DB outbox for crash-safe
  eligibility verification (`DECISIONS.md` §D3).
- Recovery job or admin endpoint for candidates stranded in
  `VERIFICATION_IN_PROGRESS`.
- Wire OpenTelemetry so the correlation id propagates as a `traceparent`
  header upstream.
- Promote the blocking executor to a true virtual-thread pool
  (`DECISIONS.md` §D6).
- Finish the P2 Terraform reference IaC (VPC + EKS + RDS + IRSA + ECR) and
